# Toasted Oats — the site at 2birds1joint.org/oats

A small Flask app that renders the brand site from three JSON files, takes waitlist
signups and pre-orders into SQLite, and runs as one gunicorn service behind a Cloudflare
tunnel. No Node, no build step, no third-party scripts, no cookies.

```
oats/              the app (python -m oats …)
  content/         products.json  site.json  faq.json  images.json   <- everything you edit
  templates/       pages + partials (Jinja)
  static/          css/ js/ fonts/ img/ (img is generated, and committed)
  tools/           slice.py (mockups -> static/img)  og.py (share image + favicons)
  tests/           pytest
art/               the four brand mockup PNGs the images are cut from
systemd/           toasted-oats.service + nightly backup timer
deploy/            cloudflared ingress snippet
install.sh         server install / update (idempotent)
oats.env.example   per-machine settings
shots.md           shot list for the real photo shoot
HANDOFF.md         deploy runbook
```

## Run it locally

```bash
python3 -m venv venv && venv/bin/pip install -r requirements-dev.txt
venv/bin/python -m oats serve          # http://127.0.0.1:8090/oats/
venv/bin/python -m oats check          # content + render sanity (run before every push)
venv/bin/pytest oats/tests -q
```

The dev server has no `OATS_PUBLIC_ORIGIN`, so it trusts `127.0.0.1:8090` and
`localhost:8090` as the site's own origin for form posts.

## Editing the site

| Want to change… | Edit |
|---|---|
| Flavor names, copy, colours, swirl/crunch text, allergen lines | `oats/content/products.json` → `flavors[]` |
| Prices, box sizes, which box is "most popular" | `oats/content/products.json` → `boxes[]` (cents) |
| Subscribe discount, cadences, free-shipping threshold, launch ETA, email, socials, nav, announcement bar | `oats/content/site.json` |
| FAQ | `oats/content/faq.json` (the first four also appear on the home page) |
| Page copy | `oats/templates/pages/*.html` — plain HTML, no logic to speak of |
| Legal pages | `oats/templates/pages/privacy.html`, `terms.html`, `accessibility.html` |

Flags in `site.json`:

- `claims_locked` — **false until the formula and Nutrition Facts are final.** While false the
  site shows "Protein-forward / Fiber-rich / …" pills and a footnote; set it true and the
  numbers in `products.json → claims.numbers` render instead (stat strip on every product
  page, numbers in search snippets). `python -m oats check` fails if a number leaks while
  it's false.
- `pricing_locked` — false shows a small "pre-order pricing" note under the boxes.
- `reviews_enabled` — keep false until there are real reviews. There are no fake stars
  anywhere, on purpose.
- `checkout.mode` — `preorder` (today), `stripe` or `shopify` (see below).
- `mode` — `full`; `coming_soon` is reserved for the launch-teaser variant.

Run `python -m oats check` after any edit: it validates colours (4.5:1 contrast on every
flavor), prices, image slots and renders every page.

## Images

`oats/static/img/` is generated by `python -m oats images` from `oats/content/images.json`
(a crop map over the four mockups in `art/`) and committed, so the server needs no image
tooling. When real photography exists, point the slots at the new files — `shots.md` lists
every slot with its ratio, minimum size and what it should show — and re-run `images`. Then
`python -m oats.tools.og` rebuilds the share image.

## Signups and pre-orders

Everything lands in SQLite at `$OATS_DB` (`/opt/oats/oats.db` on the server). No IPs, user
agents or anything else about the visitor are stored; `events` only counts honeypot hits
and rate limits.

```bash
cd /opt/oats/app && sudo -u newsfeed env $(grep -v '^#' /opt/oats/oats.env | xargs) \
  /opt/oats/venv/bin/python -m oats stats
… python -m oats export-csv preorders > preorders.csv
… python -m oats export-csv signups --since 2026-11-01 > signups.csv
```

Pre-orders carry a `ref` (`TO-XXXXXXXX`) the customer sees on the thanks page, the
normalised lines with server-computed prices, and `status` (`new` until you invoice).
A nightly timer copies the database to `/opt/oats/backup/` and keeps 30 days.

## Deploy

See `HANDOFF.md` — ten minutes: clone to `/opt/toastedoats`, `sudo ./install.sh`, enable
the service, add one Cloudflare tunnel path rule.

Why a path rule and not a subdomain: the brief says `/oats`. cloudflared forwards the full
path, and the app mounts itself under `OATS_PREFIX` with a WSGI middleware, so every link,
asset and redirect is prefixed without the templates knowing. If it ever moves to
`oats.2birds1joint.org`, set `OATS_PREFIX=` (empty) and `OATS_PUBLIC_ORIGIN` accordingly.

### Static hosting instead

`python -m oats freeze --out oats/dist --api-base https://2birds1joint.org/oats/api`
writes the whole site as files under `dist/oats/` for Cloudflare Pages or any static host;
the API still needs the Flask service somewhere (add that host to `OATS_ALLOWED_ORIGINS`).

## Switching on real checkout

Everything in the cart carries a SKU (`starter-7`, `byo-14`, `byo-28`, `single-7` +
flavor), so payments bolt on without touching the UI:

- **Stripe**: set `checkout.mode` to `stripe`, add a route that creates a Checkout Session
  from the pre-order payload (price ids per SKU go in `site.json → checkout.stripe.prices`,
  the secret key in `oats.env`), and fill in `oats/static/js/checkout.js → adapters.stripe`
  to follow the returned URL. The pre-order endpoint can stay for "notify me" flavors.
- **Shopify**: set `checkout.mode` to `shopify`, fill `checkout.shopify.domain` and a variant
  id per SKU, and build the cart permalink in `adapters.shopify`.

## Before launch — things a human must sign off

- `site.json → contact.email`, Instagram/TikTok handles, `launch.eta` are placeholders.
- Pricing is placeholder, based on category norms ($3.50–4.15 a bowl, 15% subscribe, free
  shipping at $45). Change `boxes[]` and `subscribe.discount_pct`; `check` recomputes.
- Allergen lines on each flavor are placeholders ("final per formula"). Replace with the
  co-packer's statement before the first box ships, and flip `claims_locked`.
- Terms and privacy are written in plain English from how the site actually works; have
  counsel read them. Note **Prop 65**: acrylamide forms in toasted grains and California may
  require a warning — ask before shipping there.
- The site makes nutrient-content statements only ("protein-forward"), never health or
  structure/function claims, so no FDA disclaimer is needed. Keep it that way in new copy.
- Hemp hearts: the FAQ and footer say "0% THC" — true of hulled hemp seed, but confirm the
  supplier's spec sheet says the same.
